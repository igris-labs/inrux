# Inrux documentation

Inrux is an early alpha native Rust GUI framework. These pages describe the checked-in implementation; unsupported ideas are not stable APIs.

## Start here

- [Getting started](GETTING-STARTED.md): prerequisites, clone, scaffold and first build.
- [Repository structure](REPOSITORY.md): crates, application folders and tooling.
- [Playgrounds](PLAYGROUNDS.md): run and explore all three engines.
- [VS Code](VSCODE.md): highlighting, formatting, navigation and Rust support.
- [Architecture](ARCHITECTURE.md): compilation, ownership, threads and adapters.
- [Status](STATUS.md): component/backend coverage and limitations.

## Build applications

- [Component authoring](AUTHORING.md): props, models, events, dynamic components, children, composables and state.
- [Headless components](HEADLESS-COMPONENTS.md): behavior and appearance ownership.
- [Layout](LAYOUT-COMPONENTS.md), [content components](CONTENT-COMPONENTS.md), [Switch/Progress/Meter](BOOLEAN-AND-RANGE-COMPONENTS.md).

- [Compiled CSS](CSS-ENGINE.md), [styling parts](STYLING-PARTS.md), [literal colors](STYLE-COLORS.md).
- [Adapter service contracts](ADAPTER-SERVICES.md).
