## Cannot find a component

Import the component in the parent's `<rust>` block. A file in `src/components/` does not register itself globally.

```rust
use crate::components::counter as Counter;
```

Match the alias in `<Counter />`. `Counter.iru` generates the snake_case module `counter`. Check the path and file spelling if navigation or compilation fails.

## Rust errors point into target

The compiler generates Rust under Cargo's output directory. Some Rust type errors still point there. Check the corresponding Props fields, handler signatures and bindings in `.iru`; do not patch the generated file. Run `cargo check` after a change.

## A CSS declaration fails

Inrux supports a subset, not arbitrary browser CSS or Tailwind utilities. Check the [CSS reference](/styling/css-reference). Tokens belong to each compiled sheet, interaction rules accept paint properties only, and public parts expose selected targets.

## GPUI fails to compile Metal shaders

On macOS install the required Xcode/Metal tools, or run the playground with `--features runtime-shaders`. Account for runtime shader compilation when comparing startup. A generated app can enable the facade's `gpui-runtime-shaders` feature.

## Windows cannot find the linker or SDK

Install the **Desktop development with C++** workload and a Windows SDK through Visual Studio Installer. Open a new Developer PowerShell terminal and run `rustup show active-toolchain`; select the MSVC toolchain with `rustup default stable-msvc` if needed. The [Windows installation tab](/getting-started/installation#requirements) has the full setup steps.

## A manual setup function is rejected

Use `<rust explicit>` for an authored State and setup function. Default `<rust>` uses top-level typed declarations and compiler-generated setup. Keep the closing tag as `</rust>` in both forms.

## A control is unsupported

Select, Dialog and Heartbeat are currently egui-only. Masonry/GPUI report capability errors or show support notices in the playground. Use the [support matrix](/getting-started/status) before choosing a backend.

## IntelliSense or Ctrl/Cmd-click is missing

Check language mode Inrux, workspace trust and the linked extension path. Reload VS Code after updates. Markup completion/navigation do not need a prior Cargo build, but Cargo-aware Rust projection does. Build once and rebuild after changing the imported graph. Check the Inrux output channel and [editor setup](/getting-started/vscode).

## Report a reproducible issue

Include your OS, engine, Rust version, build profile, minimal `.iru` source and exact error. Include fonts/display scale and screenshots for text differences. Include warm/cold conditions and a workload for performance reports. Open an [issue](https://github.com/igris-labs/inrux/issues).
