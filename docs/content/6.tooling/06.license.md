Original Inrux code uses the [MIT license](https://github.com/igris-labs/inrux/blob/main/LICENSE). The project does not offer a project-wide MIT/Apache dual license.

Dependencies, adapted source and fonts retain their own terms. The Masonry and GPUI adapters include Apache-2.0 adaptations with source headers and NOTICE files. Those two crates describe mixed contents through `MIT AND Apache-2.0` package metadata; original Inrux files remain MIT.

The playgrounds and shared text provider use Noto fonts under the SIL Open Font License. The website retains copies and their notices in `public/fonts/`; its configured interface/code families are Inter and JetBrains Mono through the documentation layer's font setup. Preserve their notices when redistributing those assets. The website uses the Inrux brand mark and the published Indocio layer; the layer's dependencies retain their upstream terms too.

Read [THIRD_PARTY_NOTICES.md](https://github.com/igris-labs/inrux/blob/main/THIRD_PARTY_NOTICES.md) and the checked-in license files for the source notices. When distributing a binary, review the dependencies resolved for the backend and features you selected.
