## Requirements

Use a stable Rust toolchain with Cargo and your operating system's native build tools. This alpha uses Rust edition 2024; an exact minimum supported Rust version has not been established. Install Git to clone the source.

Choose your operating system. The Cargo commands after these tabs work in macOS/Linux shells and Windows PowerShell.

::tabs{label="Installation operating system" sync="installation-os" default-value="macos"}
:::tab-item{title="macOS" value="macos"}

Install Xcode Command Line Tools, which supply a C/C++ compiler and Git:

```sh
xcode-select --install
```

Install Rust with the [official rustup installer](https://rust-lang.org/install). Open a new terminal after installation, then run:

```sh
rustup update stable
rustup component add rustfmt clippy
rustc --version
cargo --version
```

GPUI's normal shader build also needs full Xcode and its Metal compiler. If the Metal compiler is unavailable, use the `runtime-shaders` option shown below. egui and Masonry do not use that GPUI option.

:::
:::tab-item{title="Linux" value="linux"}

On Ubuntu or Debian, install the native dependencies used by the repository's Linux CI, along with Git and the C/C++ build tools:

```sh
sudo apt-get update
sudo apt-get install -y build-essential curl git cmake pkg-config clang libx11-dev libxi-dev libxcursor-dev libxrandr-dev libxinerama-dev libxkbcommon-dev libwayland-dev libgl1-mesa-dev libfontconfig1-dev libxkbcommon-x11-dev libxcb-xkb-dev libvulkan-dev libssl-dev
```

For other distributions, install the equivalent development packages. You need a graphical desktop session with X11 or Wayland to open a playground window.

Install Rust with the [official rustup installer](https://rust-lang.org/install). Open a new terminal after installation, then run:

```sh
rustup update stable
rustup component add rustfmt clippy
rustc --version
cargo --version
```

:::
:::tab-item{title="Windows" value="windows"}

Install [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) and select **Desktop development with C++**. Include the MSVC C++ tools for your machine and a Windows 10 or Windows 11 SDK. These provide the linker and native headers that Rust dependencies need. Microsoft's [Rust setup guide](https://learn.microsoft.com/en-us/windows/dev-environment/rust/setup) explains the installer selections.

Open PowerShell and install Rust and Git with WinGet:

```console [PowerShell]
winget install --id Rustlang.Rustup --exact --source winget
winget install --id Git.Git --exact --source winget
```

You can also use the [Rust installer](https://rust-lang.org/install) and [Git for Windows](https://git-scm.com/install/windows). Once the installers finish, open a new **Developer PowerShell for Visual Studio** terminal and select Rust's MSVC toolchain:

```console [Developer PowerShell]
rustup default stable-msvc
rustup update stable
rustup component add rustfmt clippy
rustup show active-toolchain
rustc --version
cargo --version
git --version
```

The active toolchain should end in `pc-windows-msvc`. The [rustup examples](https://rust-lang.github.io/rustup/examples.html) explain selecting MSVC instead of GNU.

Keep the Windows SDK installed for GPUI release builds: its shader compiler is part of that build path. Use a native Windows terminal for Windows applications. WSL users should follow the Linux tab and need a working graphical session to open windows.

:::
::

Python 3 runs repository consistency checks. Node.js 22.19 or newer and npm build the VS Code extension. The documentation website uses pnpm 10.7.1 as well. These tools are not required to build an application from a checkout with Rust and the native dependencies installed.

The CI matrix includes Linux, macOS and Windows. Backend requirements and graphics drivers can still affect native builds; this does not certify every desktop configuration. Start with egui and check the [support matrix](/getting-started/status) before choosing experimental backend features.

## Get the source

```sh
git clone https://github.com/igris-labs/inrux.git
cd inrux
```

Keep `Cargo.lock` and the checked-in `vendor/` patches. They are part of the reproducible checkout. There is no crates.io release yet.

## Run an example

From the repository root, run one application at a time:

```sh
cargo run -p inrux-playground-egui --locked
cargo run -p inrux-playground-masonry --locked
cargo run -p inrux-playground-gpui --locked
```

On macOS without the Metal compiler:

```sh
cargo run -p inrux-playground-gpui --features runtime-shaders --locked
```

The runtime shader option changes startup work; account for it in comparisons. The first build downloads and compiles native dependencies and can take substantial time. [Playground usage](/getting-started/playgrounds) explains the controls and examples.

## Create your own app

From the framework root:

```sh
cargo run -p inrux-cli -- new ../hello-inrux --framework-path . --backend egui
cd ../hello-inrux
cargo run
```

The destination must not already exist. `--framework-path` points to your Inrux checkout. Choose `egui`, `masonry` or `gpui`; the generated manifest selects only that backend. For a generated GPUI app on macOS without the Metal compiler, enable the facade's `gpui-runtime-shaders` feature in its Cargo.toml.

The generated project contains:

```text
hello-inrux/
├── Cargo.toml
├── build.rs
└── src/
    ├── main.rs
    ├── App.iru
    ├── components/Counter.iru
    ├── composables/
    └── styles/global.css
```

`build.rs` compiles `App.iru` and its imported component graph. `main.rs` includes the generated bootstrap and mounts the root. Edit `App.iru` for layout and logic; import reusable `.iru` components explicitly from its `<rust>` block. Ordinary `.rs` helpers and Cargo dependencies remain available.

The scaffold currently parses its global stylesheet once at startup. The playground build scripts show how to precompile standalone CSS into Rust as well as compiling `.iru` style blocks. See [authoring](/authoring/component-contract) and [styling](/styling/css-reference).

## Development commands

You may install the local CLI once:

```sh
cargo install --path packages/inrux-cli --locked
```

Then, from an application directory, use `cargo inrux check`, `cargo inrux run` or `cargo inrux dev`. The development command watches sources and rebuilds/restarts the process; it does not preserve application state. Plain Cargo commands continue to work. See the [CLI README](https://github.com/igris-labs/inrux/blob/main/packages/inrux-cli/README.md).

For `.iru` formatting and Rust editing features, follow [VS Code setup](/getting-started/vscode). For reproducible bug reports, include `rustc --version`, your OS and selected backend.
